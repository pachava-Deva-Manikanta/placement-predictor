# placement-predictor

This project predicts whether a student is likely to be *Placed* or *Not Placed* based on their academic and personal profile using various machine learning models.

## 📊 Project Description

The goal of this project is to build a machine learning model that helps colleges predict a student's placement status based on input features like:

- Academic Scores (SSC, HSC, Degree %)
- Specialization
- Work Experience
- Employability Test Score
- and more...

It also includes a *Streamlit web app* for live predictions.
